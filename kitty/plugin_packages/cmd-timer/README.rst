Command timer
=============

Kick off a slow build and walk away: when a long command finishes in a window you are not looking at, a desktop notification tells you what finished, whether it worked and how long it took.

Needs kitty shell integration. The minimum duration and whether to notify even for the focused window are on the plugin settings page.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: events, notify, settings.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
