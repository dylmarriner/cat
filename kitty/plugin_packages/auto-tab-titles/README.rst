Smart tab titles
================

Tabs name themselves: while a command runs the tab shows what it is with an icon (🐍 python, 🦀 cargo, 🐳 docker, ⎈ kubectl, 🌐 ssh host…), and at the prompt it shows the Git repository and branch you are in.

Needs kitty shell integration. To get your own tab titles back, disable the plugin.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: background, events, tabs, window.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
