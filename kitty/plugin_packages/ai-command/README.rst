AI command
==========

Say what you want in plain words — “find the 10 biggest files changed this week”, “undo my last commit but keep the changes” — and Claude types the matching shell command at your prompt for you to check and run.

Run ``ask`` and describe what you want. The command is typed but never run. Uses Claude Code (the ``claude`` command) with your existing login, no API key needed.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: background, commands, tabs, terminal, ui, window.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
