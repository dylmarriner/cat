Daylight themes
===============

Your terminal follows the sun: colors drift continuously from deep night blue through dawn rose and crisp daylight to dusk amber as the hours pass.

Enabled immediately; colors update every minute. Run ``preview`` to watch a whole day pass in 12 seconds, ``pause`` to stop and restore your normal colors, ``resume`` to start again.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: appearance, commands, timers, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
