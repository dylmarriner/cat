Streak fireworks
================

Gamifies your shell: every successful command builds a streak, and streak milestones launch fireworks over the terminal. A failure resets the streak.

Needs kitty shell integration. Milestones are 5, 10, 25, 50, 100 and every 100 after that. Run ``status`` to see your current and best streak, ``test`` to launch fireworks now.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, events, notify, shaders, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
