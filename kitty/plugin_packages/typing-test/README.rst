Typing test
===========

How fast do you really type code? A typing test made of real shell, Python, Rust and JavaScript lines, with live per-character feedback, WPM, accuracy and a personal best.

Run ``start``. The timer starts with your first key. Tab gives a new text, Escape quits.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, launch, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
