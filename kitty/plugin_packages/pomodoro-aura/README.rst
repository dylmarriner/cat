Pomodoro aura
=============

A focus timer you can feel: a glowing progress bar across the top of kitty, and an aura that warms from cool teal to amber as the focus session runs out. Breaks breathe in soft green.

Run ``start`` to begin a 25 minute focus session, ``stop`` to end it and ``skip`` to jump to the next phase. Durations are on the plugin settings page.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, notify, settings, shaders, timers, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
