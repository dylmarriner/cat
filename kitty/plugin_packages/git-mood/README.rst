Git mood light
==============

An ambient light that shows the state of the repository you are in: calm green when clean, amber with changes, red during merge conflicts, violet when ahead of the remote, blue on a detached HEAD.

Updates when you focus a window and after every command (shell integration). Outside a Git repository the light switches off.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: background, events, shaders, window.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
