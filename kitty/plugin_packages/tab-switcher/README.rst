Tab switcher
============

Use kitty's built-in chooser to find and focus a tab by title. It has no fzf or
jq dependency. Run ``tab-switcher`` from the plugin command list or assign it a
key mapping in kitty's plugin settings.

Source inspiration: https://github.com/OsiPog/kitty-tab-switcher

This implementation uses kitty's plugin API and does not include upstream code.
