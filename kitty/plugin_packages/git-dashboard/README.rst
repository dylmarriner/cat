Git dashboard
=============

Everything about the repository you are in on one screen: branch and upstream drift, staged / changed / untracked files with diff stats, stashes, and a colored commit graph.

Run ``open`` in a window inside a Git repository. ``r`` refreshes, ``q`` closes.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, launch, ui, window.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
