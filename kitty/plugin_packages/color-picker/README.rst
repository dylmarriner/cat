Color picker
============

A true color picker inside your terminal: steer hue, saturation and lightness with the keyboard, see a big live swatch with complementary and analogous harmonies, and copy the result as hex, rgb() or hsl().

Run ``pick``. Left/Right hue, Up/Down lightness, ``[``/``]`` saturation (hold Shift-style capitals ``H``/``L``/``S`` for big steps), Tab changes the format, Enter copies, Escape cancels.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: clipboard, commands, launch, notify, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
