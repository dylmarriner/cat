System monitor HUD
==================

A heads-up display over your terminal: per-core CPU bars, memory and swap gauges, network throughput sparklines, load and the hungriest processes, refreshed every second.

Run ``open``. Press ``q`` or Escape to close. Reads ``/proc``, so it works on Linux.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, launch, ui, window.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
