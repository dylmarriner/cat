Snake
=====

The classic, rendered in true color inside a kitty overlay: a gradient snake that speeds up as it grows, glowing food, wrap-free walls and a high score that survives restarts. For compile breaks.

Run ``play``. Arrow keys or WASD steer, Space pauses, ``r`` restarts, ``q`` quits.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, launch, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
