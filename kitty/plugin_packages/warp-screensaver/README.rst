Warp screensaver
================

Leave kitty idle and it jumps to hyperspace: a starfield streaks out from the center of the screen over your terminal. Touch anything and you drop back to normal space.

Starts when kitty considers you idle, set with ``cursor_stop_blinking_after`` in kitty.conf, and rests after 15 minutes to save power. Run ``toggle`` to switch it off and on.

Install it from kitty's command palette with **Install bundled plugin**, then
**Review and enable**. Requested capabilities: commands, shaders, ui.

Original code written for kitty's plugin API, distributed under GPL-3.0-or-later.
